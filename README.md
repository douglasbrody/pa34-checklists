# PA-34-200 Checklists

Offline checklist viewer for iPad. Big tiles, text that resizes to fit the screen, Day / Night / Red modes.

**Install:** open https://douglasbrody.github.io/pa34-checklists/ in Safari on the iPad → Share → **Add to Home Screen** → open it once from the icon while online. After that it works in airplane mode.

**Updating:** edit checklists in the app (Edit button), or regenerate `defaults.js` from the spreadsheet with `tools/convert_xlsx.py` and bump `VERSION` in `sw.js`.
